# 배관 컴포넌트 AI 인식 모듈 — 프로그램 실행 매뉴얼

> **pipe-component-ai** : BIM(Revit) 패밀리 JSON의 형상·커넥터·속성 피처를 기반으로
> 배관 컴포넌트(밸브/피팅/플랜지 등)를 자동 분류하는 LightGBM 기반 AI 모듈

---

## 1. 개요

본 모듈은 Revit 패밀리에서 추출한 BIM JSON 데이터를 입력으로 받아, 다음 두 단계의 분류를 수행한다.

1. **컴포넌트 그룹 분류** — VALVE, FITTING, FLANGE, GASKET, SUPPORT, INSTRUMENT 등 15개 그룹
2. **밸브 타입 분류** — VALVE로 분류된 경우 BALL, GATE, GLOBE, BUTTERFLY, CHECK 등 세부 타입

학습 파이프라인은 두 가지 버전으로 구성되어 있다.

| 버전 | 레이블 출처 | 데이터 범위 | 교차검증 | 출력 폴더 |
|------|-------------|-------------|----------|-----------|
| **v1** (`run_pipeline.py`) | `학습용레이블_정답.xlsx` + 파일명 fallback | 단일 폴더 (55개 샘플) | LeaveOneOut-CV | `models/` |
| **v2** (`run_pipeline_v2.py`) | `전문가_정의_csv/` CSV 레이블 | TrainingModel 다중 폴더 (181개 모델) | Stratified 5-Fold | `models_v2/` |

> **현재 권장 버전은 v2**이다. 전문가 정의 CSV 기반으로 데이터 규모가 크고 정확도가 높다(약 0.95).

## 2. 사전 준비

### 2.1 실행 환경

- **OS** : Windows (한글 폰트 `Malgun Gothic` 기준으로 그래프 생성)
- **Python** : 3.12 (코드의 `cpython-312` 캐시 기준)
- C# / DevExpress WinForm 측 연동 시에는 본 모듈을 FastAPI 서버로 띄워 REST API로 호출

### 2.2 패키지 설치

`pipe-component-ai` 폴더에서 다음을 실행한다.

```bat
cd pipe-component-ai
pip install -r requirements.txt
```

`requirements.txt` 주요 패키지:

```
lightgbm>=4.0.0      # 분류 모델
scikit-learn>=1.3.0  # 교차검증, 스케일링, 평가
pandas>=2.0.0        # 데이터 처리
numpy>=1.24.0
fastapi>=0.110.0     # 추론 API 서버
uvicorn[standard]    # ASGI 서버
pydantic>=2.0.0      # 입출력 스키마
joblib>=1.3.0        # 모델 직렬화
matplotlib>=3.7.0    # 시각화
seaborn>=0.12.0
```

### 2.3 데이터 폴더 구조

모듈은 상위 폴더의 `BIM모델_데이터/`를 데이터 소스로 사용한다.

```
배관ISO 논문 작업/
├── BIM모델_데이터/
│   ├── TrainingModel/            # v2 학습용 모델별 폴더 (모델당 JSON 묶음)
│   │   ├── {모델명1}/
│   │   │   ├── {부재}.json
│   │   │   └── ...
│   │   └── {모델명2}/ ...
│   ├── 전문가_정의_csv/           # v2 레이블 CSV (모델명.csv)
│   │   └── {모델명}.csv          # 컬럼: FamilyAndTypeName, ItemKey, RevitId
│   ├── 학습용레이블_정답.xlsx     # v1 레이블 (ProductCode, SKY 컬럼)
│   └── symbol.xml                # SKEY → 컴포넌트 그룹/밸브 타입 매핑 정의
└── pipe-component-ai/            # 본 모듈
```

> **CSV 레이블 규칙(v2)**
> - `ItemKey` 가 SKEY 코드
> - `NC**` → 미정 항목, 학습에서 제외(`nc_pending_labels.csv`에 기록)
> - `_P**` → 파이프 타입, 학습에서 제외

## 3. 실행 방법

### 3.1 v2 학습 파이프라인 (권장)

가장 간단한 실행 방법은 배치 파일이다.

```bat
cd pipe-component-ai
run_v2.bat
```

또는 직접 실행:

```bat
python run_pipeline_v2.py
```

**수행 단계 (자동)**

1. `TrainingModel/` + `전문가_정의_csv/` 로드 → 피처·레이블 매칭
2. NC** 항목 분리 저장 (`models_v2/nc_pending_labels.csv`)
3. 피처 행렬 구성
4. Stratified 5-Fold 교차검증 학습
5. 전체 데이터로 최종 모델 학습 후 저장
6. 평가 리포트(분류 리포트, 혼동 행렬, 피처 중요도) 생성

**출력물** (`models_v2/`)

| 파일 | 설명 |
|------|------|
| `group_classifier.pkl` | 학습된 LightGBM 그룹 분류 모델 |
| `group_scaler.pkl` | StandardScaler |
| `feature_cols.pkl` | 사용 피처 컬럼 목록 |
| `int_to_group.pkl` | 정수 라벨 → 그룹명 매핑 |
| `dataset.csv` | 최종 학습 데이터셋 |
| `classification_report.csv` | 클래스별 정밀도/재현율/F1 |
| `confusion_matrix.csv` | 혼동 행렬 |
| `feature_importance.csv` | 피처 중요도 |
| `fold_accuracies.csv` | Fold별 정확도 |
| `nc_pending_labels.csv` | 미정(NC) 항목 목록 |

> 참고 실측치: 5-Fold 정확도 약 **0.94 ~ 0.96** (평균 ≈ 0.95)

### 3.2 시각화 그래프 생성

학습 완료 후 논문용 그래프(PNG)를 생성한다.

```bat
run_plots.bat
```

또는:

```bat
python generate_plots.py
```

생성물(`models_v2/`): `confusion_matrix.png`, `feature_importance.png`, `fold_accuracy.png`, `classification_report.png`, `class_distribution.png`, `version_comparison.png`

### 3.3 v1 학습 파이프라인 (참고용)

```bat
python run_pipeline.py --data_dir ../BIM모델_데이터
```

**주요 옵션**

| 옵션 | 설명 |
|------|------|
| `--data_dir` | (필수) BIM JSON 폴더 경로 |
| `--model_dir` | 모델/결과 저장 폴더 (기본값 `models`) |
| `--ablation` | 피처 그룹별 Ablation Study 수행 |
| `--infer` | 학습 후 `data_dir` 전체 배치 추론 수행 |
| `--output_csv` | 배치 추론 결과 CSV 저장 경로 |

예시:

```bat
python run_pipeline.py --data_dir ../BIM모델_데이터 --ablation --infer
```

> v1 실측치: 그룹 분류 LOO-CV 정확도 약 0.82, 밸브 타입 약 0.38 (소규모 데이터)

## 4. 추론(예측) 실행

### 4.1 배치 추론 (CLI)

폴더 내 모든 JSON을 일괄 예측한다.

```bat
python -m src.predict --json_dir <JSON폴더경로> --model_dir models --output_csv result.csv
```

| 옵션 | 설명 |
|------|------|
| `--json_dir` | (필수) 예측할 JSON 파일 폴더 |
| `--model_dir` | 모델 폴더 (기본값 `models`) |
| `--output_csv` | 결과 CSV 저장 경로 |

**출력 항목** : `component_group`, `group_confidence`, `valve_type`, `type_confidence`, `review_required`(검토 필요 여부), `review_reason`

**신뢰도 규칙**

| 신뢰도 | 상태 | 의미 |
|--------|------|------|
| ≥ 0.90 | auto | 자동 처리 |
| 0.70 ~ 0.90 | review | 검토 권장 |
| < 0.70 | unknown | 신뢰도 낮음 |

### 4.2 FastAPI 추론 서버

C#/DevExpress WinForm 등 외부 프로그램과 연동할 때 사용한다.

```bat
cd pipe-component-ai
uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload
```

실행 후 브라우저에서 **Swagger UI** 접속:

```
http://localhost:8000/docs
```

> 기본 모델 폴더는 `models/`. 환경변수 `MODEL_DIR`로 변경 가능
> (예: `set MODEL_DIR=models_v2` 후 실행)

**API 엔드포인트**

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/health` | 서버 상태 / 모델 로드 여부 |
| POST | `/predict` | 피처 벡터(JSON) → 분류 결과 |
| POST | `/predict/file` | Revit BIM JSON 파일 업로드 → 분류 결과 |
| POST | `/predict/batch` | 여러 JSON 파일 업로드 → 배치 결과 |
| GET | `/model/info` | 로드된 모델 정보 |

**호출 예시 (피처 벡터)**

```bat
curl -X POST http://localhost:8000/predict ^
     -H "Content-Type: application/json" ^
     -d @request_body.json
```

`/predict`는 C# Revit Add-in에서 추출한 24개 수치 피처를 그대로 전달하는 용도이며,
`/predict/file`은 원본 BIM JSON을 업로드하면 서버에서 피처를 추출해 분류한다.

## 6. 자주 발생하는 문제

| 증상 | 원인 / 해결 |
|------|-------------|
| `모델이 로드되지 않았습니다 (503)` | 학습을 먼저 수행하거나, `MODEL_DIR`가 올바른 모델 폴더를 가리키는지 확인 |
| `그룹 분류기를 찾을 수 없습니다` | `models/`(또는 `models_v2/`)에 `*.pkl` 모델 파일이 없음 → 학습 재실행 |
| `JSON 파일을 찾을 수 없습니다` | `--data_dir` / `--json_dir` 경로 확인 |
| `유효한 학습 데이터가 없습니다` | CSV 레이블과 JSON의 FamilyName 매칭 실패 → CSV 컬럼명/경로 확인 |
| 그래프 한글 깨짐 | `Malgun Gothic` 등 한글 폰트 설치 여부 확인 |
| FastAPI 서버에서 v2 모델 사용하려는데 미반영 | `set MODEL_DIR=models_v2` 후 서버 재시작 |
